# Bipedal Robot

This project focuses on the design and control of a 3-DOF bipedal robot leg using an ESP32 microcontroller and servo motors. The objective was to study robotic locomotion through kinematic analysis and embedded control.

## Features

- 3-DOF robot leg
- Servo motor control using PWM
- Forward and inverse kinematics
- Walking gait implementation
- ESP32-based control system

## Hardware Used

- ESP32 Development Board
- MG996R Servo Motors
- Mechanical Frame
- External Power Supply

## Software Used

- Arduino IDE
- C++
- Servo Library

## Working

The ESP32 generates PWM signals to control the servo motors. Joint angles calculated using kinematic equations are used to generate coordinated hip and knee movements, allowing the robot leg to perform a basic walking sequence.
